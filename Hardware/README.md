# Hardware do Projeto

**Observação:** Se o projeto não envolver hardware (projeto apenas em software), mantenha este diretório em branco ou ignore-o.

Mantenha neste diretório os artefatos relacionados ao hardware do projeto.

## Estrutura sugerida

* **`/esquematicos`** — Esquemáticos de circuito (KiCad, Eagle, Fritzing, etc.).
* **`/pcb`** — Arquivos de projeto de placa de circuito impresso (PCB).
* **`/lista_componentes`** — Lista de materiais (BOM), datasheets e especificações.

Descreva neste arquivo a arquitetura do hardware, componentes principais e instruções para reprodução do circuito.
